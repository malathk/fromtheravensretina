# A Quantum Compass, Rendered

An interactive WebGL visualisation of the radical-pair hypothesis for avian
magnetoreception.

The work has two connected views:

- Raven’s perspective — a stylised visual field in which an abstract
  magnetic modulation changes with the bird’s orientation.
- Inside the eye — a retinal map that can be clicked to enter a stylised
  cryptochrome radical pair.

## Interaction

- **Drag** anywhere to change the raven’s heading and pitch.
- **Click the right-hand retinal view** to zoom into the molecular spin state.
- **Double-click** to return to the retinal view.

## What the visualisation proposes

The radical-pair hypothesis proposes that light activates cryptochrome proteins
in the avian retina, producing radical pairs whose electron spins may remain
correlated briefly. Their singlet and triplet character can evolve differently
depending on molecular orientation relative to Earth’s magnetic field.

If those spin-dependent chemical outcomes vary across the retina, they could
produce an orientation-dependent visual modulation pattern. This does not mean
that a bird sees a compass needle. It suggests a possible way in which magnetic
direction might become available to the visual system.

## What is simplified

This is a designed scientific illustration, not a quantum-chemical simulation.

The visualisation does not model the complete cryptochrome protein, its flavin
cofactor, the full set of nuclear spins, molecular motion, thermal noise,
neural processing, or the actual visual system of a raven.

The molecular view is intentionally schematic: it makes the relationships
between donor and acceptor radicals, electron spins, nuclear spins, and
singlet–triplet dynamics visible.
